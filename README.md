# SkillBridge – Smart Internship & Placement Portal

A premium, static, multi-page web app built with plain HTML, CSS and JavaScript.

## How to run
Just open `index.html` in any modern browser. No build step, no server required.

## Pages
- index.html — Home
- internships.html — Listings, search, filter, modal
- about.html, contact.html
- student-login.html, student-register.html, student-dashboard.html
- company-login.html, company-register.html, company-dashboard.html
- admin-login.html, admin-dashboard.html

## Features
- Glassmorphism + soft shadows, gradient accents, dark mode (localStorage)
- Sticky responsive nav with mobile drawer
- Animated counters, reveal-on-scroll, hover transitions, page loader
- Client-side form validation for every auth + contact form
- Internship search & filter with detail modal
- Demo dashboards for student, company, admin (tables, KPIs, notifications)
- Toast notifications and reusable modal helper

Built for Smart India Hackathon.
